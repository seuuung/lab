조건문

만약 점수 >= 90:
    출력("우수")

    출력("통과")
아니면:
    출력("다시 도전")

반복문

반복 3번:
    출력("안녕")

반복 숫자 각각 범위(1, 4):
    출력(숫자)

숫자 = 0
동안 숫자 < 3:
    숫자 += 1

반복 값 각각 목록에서:의 에서는 생략할 수 있습니다. 반복문 안의 그만은 반복을 종료하고, 계속은 다음 차례로 넘어갑니다. 기존 표기 반복 조건인동안:, 반복끝내기, 다음반복도 지원합니다.

LANGUAGE / 04

함수와 변수 범위

함수 제곱(숫자):
    돌려주기 숫자 * 숫자

출력(제곱(5))  # 25

함수는 함수 이름(매개변수):로 선언합니다. 돌려주기는 값을 반환하고, 반환값을 쓰지 않으면 없음을 반환합니다. 재귀 호출을 지원하며 최대 깊이는 40입니다.

매개변수와 함수 안에서 처음 만든 변수는 지역 변수입니다. 함수 안에서 이미 바깥에 있는 변수에 대입하면 바깥 값이 갱신됩니다.

위치 = 0
함수 이동():
    위치 += 2  # 바깥의 위치를 갱신
    임시 = 위치  # 새 지역 변수
LANGUAGE / 05

목록과 사전

목록과 문자열의 인덱스는 0부터 시작합니다. [시작:끝]은 끝 직전까지 잘라냅니다. 목록·사전의 요소를 수정할 수 있습니다.

학생 = {
    "이름": "세종",
    "점수": [90, 85, 100]
}
학생["점수"][0] = 95
출력(학생["이름"])
출력(학생["점수"][0:2])  # [95, 85]

사전 키는 문자열 또는 숫자입니다. 없는 키를 읽거나 목록 범위를 벗어난 인덱스를 사용하면 오류가 납니다. 직접 인덱싱에서 음수 인덱스는 지원하지 않습니다.

RUNTIME / 07

입출력과 오류

이름 = 입력("이름을 입력하세요")
출력("안녕하세요, " + 이름)

입력(안내 문구)는 문자열 입력을 기다립니다. 숫자가 필요하면 정수(입력(...)) 또는 실수(입력(...))로 변환하세요. 입력 창에서 취소하거나 실행을 중단하면 프로그램이 종료됩니다.

오류에는 줄 번호와 유형이 표시됩니다. 구문 오류, 이름·함수 오류, 자료형 오류, 인덱스·키 오류, 0 나누기 오류, 제한 오류를 구분합니다. 오류 줄이 편집기에서 선택되므로 해당 줄과 앞선 변수 선언을 확인하세요.

CANVAS / 08

그래픽 API

그림 좌표의 원점은 왼쪽 위입니다. x는 오른쪽, y는 아래쪽으로 증가합니다. 그래픽 명령의 결과는 그림 탭에 표시됩니다.

화면만들기(가로, 세로)

Canvas 크기를 설정하고 화면을 초기화합니다. 가로 1–1600, 세로 1–1200.

배경색(색상)

화면 전체를 지정한 색으로 채웁니다.

색상설정(색상)

이후 도형과 글자의 색을 설정합니다.

원그리기(x, y, 반지름)

중심 좌표와 반지름으로 채운 원을 그립니다.

사각형그리기(x, y, 가로, 세로)

왼쪽 위 좌표에서 채운 사각형을 그립니다.

선그리기(x1, y1, x2, y2)

두 좌표를 잇는 선을 그립니다.

글자그리기(내용, x, y)

현재 색으로 20px 글자를 그립니다.

화면지우기()

Canvas를 투명하게 지웁니다.

색상에는 검정, 흰색, 빨강, 파랑, 초록, 노랑, 하늘색, 보라 또는 "#12354b" 같은 CSS 색상을 사용할 수 있습니다.

TOOLS / 10

Python 비교

Python 비교 버튼은 한글 구문 트리에서 대응 코드를 생성합니다. 결과를 복사할 수 있으며 Python 실행 환경을 제공하지는 않습니다. 반복 … 각각 범위()는 for … in range()로 변환됩니다.

Canvas·애니메이션 명령은 Python에서 실행되지 않아 주석으로 표시됩니다. 한글 코드의 문자열 + 자동 변환 등 Python과 다른 동작에는 경고가 표시됩니다.

RUNTIME / 11

실행 제한과 보안

소스 길이최대 100,000자일반 실행최대 3초, 60,000단계함수 호출재귀 깊이 40콘솔최대 250줄, 한 줄 2,000자목록·사전최대 5,000개 항목그래픽프레임당 최대 500명령

프로그램은 별도의 Web Worker에서 해석되며 사용자 코드를 JavaScript eval로 실행하지 않습니다. 한글 코드에서 DOM, 파일, 네트워크, 브라우저 저장소에 직접 접근할 수 없습니다. 입력을 기다리거나 애니메이션이 실행되는 동안에는 3초 제한을 멈추며 중단 버튼으로 종료합니다.
