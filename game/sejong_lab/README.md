# 세종 개발실 0.2

**코딩도 우리말로.** 브라우저에서 한글 코드를 작성하고 실행하는 정적 웹 IDE입니다. Lexer → Parser → AST 해석기를 Web Worker에서 실행하며, 서버나 외부 라이브러리가 필요하지 않습니다.

## 실행

`index.html`을 브라우저에서 엽니다. 로컬 파일에서 Worker 생성이 막히는 브라우저에서는 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접속합니다. GitHub Pages와 Cloudflare Pages에는 `index.html`을 그대로 배포할 수 있습니다. 코드는 브라우저 밖으로 전송되지 않습니다.

## 사용

- 왼쪽(모바일에서는 상단)에서 12개 예제를 고릅니다. 편집 중인 코드가 예제와 다르면 교체를 확인합니다.
- **실행하기** 또는 `Ctrl/⌘ + Enter`로 실행하고 **중단**으로 입력 대기·애니메이션을 종료합니다.
- 모바일에서는 **코드 / 결과 / 그림** 탭으로 화면을 바꿉니다.
- 휴대폰에서는 실행·중단 버튼이 도구줄 왼쪽에 유지되고 나머지 도구는 가로로 스크롤합니다. 개발 문서는 화면 전체로 펼쳐집니다.
- 오른쪽 아래 **한글 문서**를 눌러 플로팅 개발 문서를 펼칩니다. 검색과 목차로 문법·기본 함수·그래픽 API를 찾고, 닫기 버튼이나 `Esc`로 접습니다.
- 편집기는 문법 강조, 줄 번호, 자동 들여쓰기·괄호 닫기, 키워드 추천(Tab으로 선택), 코드 정리, 로컬 자동 저장을 지원합니다.
- **Python 비교**는 AST를 Python으로 변환해 나란히 보여주며 복사할 수 있습니다. 브라우저 전용 그래픽 명령은 주석으로 표시합니다.
- **내려받기**는 `.세종` 파일을 저장합니다. **공유**는 정적 사이트에서 코드가 포함된 링크를 복사합니다(최대 4,000자). 로컬 파일에서는 코드 자체를 복사합니다.

## 한글 문법

```text
학생 = {"이름": "세종", "점수": [90, 85, 100]}
학생["점수"][0] = 95
출력(학생["점수"][0:2])

함수 짝수인가(숫자):
    만약 숫자 % 2 == 0:
        돌려주기 참
    아니면:
        돌려주기 거짓

반복 숫자 각각 범위(1, 11):
    만약 짝수인가(숫자):
        출력(숫자)

이름 = 입력("이름을 입력하세요")
출력("안녕, " + 이름)
```

4칸 들여쓰기를 권장합니다. `동안 조건:`, `반복 횟수번:`, `반복 항목 각각 목록에서:`, `그만`, `계속`, `돌려주기`, `#` 주석을 지원합니다. 기존 `반복 조건인동안:`, `반복끝내기`, `다음반복`, `글자열()`도 유지합니다. 함수의 매개변수와 새 이름은 지역 변수입니다. 함수에서 이미 존재하는 바깥 변수를 대입하면 그 값을 갱신합니다.

자료구조는 목록, 사전, 인덱싱, 슬라이싱, 요소 변경을 지원합니다. 내장 함수: `출력`, `입력`, `길이`, `범위`, `합계`, `최댓값`, `최솟값`, `정렬`, `추가`, `삭제`, `문자열/글자열`, `정수`, `실수/숫자`, `절댓값`, `무작위`.

## 그래픽

```text
화면만들기(600, 320)
위치 = 0
함수 그리기():
    배경색("검정")
    색상설정("하늘색")
    원그리기(위치, 160, 28)
    위치 += 2
    만약 위치 > 600:
        위치 = 0
매프레임(그리기)
```

Canvas 명령: `화면만들기`, `배경색`, `색상설정`, `원그리기`, `사각형그리기`, `선그리기`, `글자그리기`, `화면지우기`. `매프레임`은 매개변수 없는 함수를 화면 갱신마다 호출합니다. 중단 버튼으로 Worker와 애니메이션을 함께 종료합니다.

## 개발과 검증

- `index.template.html`: 화면 구조
- `styles.css`: 반응형 디자인
- `docs.reference.html`: IDE에 포함되는 한글 공식 참조 문서
- `app.js`: 편집기, 예제, Worker 메시지, Canvas
- `engine.js`: Lexer, Parser, AST 실행기, Python 변환
- `interpreter.js`: 이전 0.1 실행기 참고용(현재 빌드에는 미포함)
- `build.py`: `index.html`과 `sejong-lab.html` 단일 파일 빌드
- `engine.test.js`: 문법·예제·오류·제한 회귀 테스트
- `worker.test.js`: 입력 대기·종료·재시작·애니메이션 테스트
- `static.test.js`: 단일 HTML 빌드와 화면 요소 점검
- `docs.test.js`: 플로팅 문서 열기·닫기와 검색 동작 검사

```sh
node engine.test.js
node worker.test.js
python build.py
node static.test.js
node docs.test.js
```

## 제한 사항

한 번 실행에 최대 60,000단계, 출력 250줄(줄당 2,000자), 재귀 깊이 40, 목록·사전 5,000개 항목을 허용합니다. 일반 실행은 3초가 지나면 Worker를 종료합니다. 입력 대기와 애니메이션 중에는 이 시간 제한을 멈추며, 그래픽 명령은 프레임당 500개로 제한합니다. 한글 코드에서는 파일·네트워크·DOM·브라우저 저장소에 직접 접근할 수 없습니다.

Python 비교는 학습용 변환입니다. Canvas와 애니메이션은 Python 코드에서 실행되지 않습니다. 한글 코드의 문자열 `+` 자동 변환 등 일부 동작은 Python과 다를 수 있으므로 생성 코드를 검토하세요.
